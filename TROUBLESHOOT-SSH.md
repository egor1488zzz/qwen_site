# Если не пускает по SSH (Permission denied)

## 1. Сброс старого пароля через панель хостинга
Сервер 2.26.10.224 (macloud/serv.host): в панели управления https://my.serv.host
выберите сервер → «Управление» / «Доступ» → **Сбросить пароль root** (Reset password).
После сброса перезагрузите сервер и войдите новым паролем.

## 2. Проверка раскладки
В Windows при вводе пароля убедитесь, что раскладка EN (индикатор RU/EN на панели задач),
регистр Caps Lock выключен. Пароль вводится «вслепую» — символы не отображаются, это нормально.

## 3. Вход по ключу вместо пароля (надёжнее)
На локальной машине (Windows PowerShell):
```powershell
ssh-keygen -t ed25519
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh-copy-id root@2.26.10.224
```
Если ssh-copy-id нет — просто скопируйте содержимое id_ed25519.pub
и вставьте в файл /root/.ssh/authorized_keys на сервере (через веб-консоль my.serv.host).

## 4. Веб-консоль как запасной вариант
my.serv.host → ваш сервер → «Веб-терминал» / «VNC-консоль» — там пароль не нужен извне,
работает логин панели. Все команды из DEPLOY-PHP.md можно выполнить там же.
